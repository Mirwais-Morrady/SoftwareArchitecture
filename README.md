# Software Architecture — GNUstep Analysis

**Course:** CISC 322 Software Architecture  
**Team:** QuantumLoop  
**Institution:** Queen's University

---

## Overview

This project is a comprehensive architectural analysis of **GNUstep**, an open-source implementation of the OpenStep/Cocoa specification that provides a cross-platform foundation for building desktop and server applications. The work was completed across three assignments, progressively deepening the analysis from high-level design concepts to concrete implementation details and, finally, proposing targeted architectural enhancements.

The goal was to apply formal software architecture techniques to a real-world, large-scale open-source system — developing skills in reading unfamiliar codebases, modeling complex systems, and reasoning about architectural tradeoffs.

---

## Project Assignments

### A1 — Conceptual Architecture
Studied GNUstep from the outside in, using documentation, source code exploration, and architectural reasoning to produce a high-level model of its subsystems and their relationships. Deliverables include a written report and a presentation.

### A2 — Concrete Architecture
Validated and refined the conceptual model against GNUstep's actual implementation using static analysis and source-level investigation. Identified how the real system differs from the conceptual ideal, documented component dependencies, and produced updated architectural diagrams. Deliverables include a written report and a presentation.

### A3 — Enhancement Proposal
Proposed concrete, architecturally-grounded improvements to GNUstep. Each enhancement was evaluated against the existing architecture for feasibility, impact, and alignment with the system's design principles. Deliverables include a written proposal and a presentation.

---

## Skills Developed

- Reverse-engineering the architecture of a large, unfamiliar open-source codebase
- Applying architectural styles and patterns (layered, subsystem decomposition, etc.)
- Producing formal architecture documentation and diagrams
- Analyzing the gap between intended (conceptual) and actual (concrete) architecture
- Technical writing and presenting complex systems to a technical audience
- Collaborative software engineering and version control with Git
